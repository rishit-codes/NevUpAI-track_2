# NevUp AI Trading Coach - Core Engine (Track 2)

A stateful, containerized API engine built for the NevUp Hiring Hackathon 2026. This system acts as the backbone for an AI Trading Psychology Coach, featuring a highly reliable persistent memory contract, multi-tenant row-level security, rule-based behavioral pathology detection, and an SSE (Server-Sent Events) streaming interface for LLM-based coaching.

## 🚀 Key Features

*   **Behavioral Pathology Classifier**: A deterministic rule-based engine capable of analyzing trade histories and detecting 9 specific trading pathologies (e.g., *Revenge Trading*, *Overtrading*, *Session Tilt*, *FOMO Entries*).
*   **Persistent Memory Contract**: Contextual awareness and data-store integration that guarantees zero-loss round trips (`UPSERT` and `GET`). Includes tenancy enforcement to prevent cross-tenant data leakage.
*   **SSE Streaming Coaching**: Real-time server-sent events interface for LLM-generated coaching messages, ensuring strict adherence to the specified JSON schema outputs.
*   **Zero-Manual-Step Deployment**: Fully containerized with Docker Compose. Automatically runs Alembic database migrations and injects seed datasets on startup.
*   **Strict Tenancy & Audit**: Mandatory `sub` claim extraction from JWTs enforcing row-level tenancy (`403 Forbidden` across tenants). Also includes an `/audit` endpoint to mitigate LLM hallucination by verifying session existence.

## 🛠 Tech Stack

*   **Framework**: FastAPI (Python 3.12)
*   **Database**: PostgreSQL 16 (via `asyncpg`)
*   **ORM**: SQLAlchemy 2.0 (Async) + Alembic for migrations
*   **Testing**: Pytest + `httpx` + `pytest-asyncio`
*   **Containerization**: Docker & Docker Compose
*   **Validation**: Pydantic v2

## ⚙️ Getting Started

The project requires no manual configuration beyond having Docker installed. 

### 1. Launch the Application

Build and start the PostgreSQL database and FastAPI application:
```bash
docker-compose up -d --build
```
*On startup, the app container will automatically run `alembic upgrade head` and populate the database via `scripts/seed.py` using the provided JSON dataset.*

### 2. Verify Health
Once the containers are running, check the health endpoint:
```bash
curl http://localhost:8000/health
```

### 3. API Documentation
Access the interactive OpenAPI (Swagger) documentation natively generated by FastAPI:
*   [http://localhost:8000/docs](http://localhost:8000/docs)

## 🧪 Testing

The repository contains a robust test suite covering all 9 pathology rules, API integration points, and row-level tenancy constraints.

Run the test suite using `pytest`:
```bash
# Locally
python -m pytest -v

# Or via Docker
docker-compose exec app pytest -v
```

### Evaluating the Classifier
An evaluation harness is included to benchmark the behavioral classifier against the seed dataset labels. To run the evaluation and output the Macro/Micro F1 scores:
```bash
python scripts/eval.py
```

## 🔒 Authentication
All endpoints require a `Bearer <token>` utilizing `HS256`. For testing purposes, you can generate an access token for a valid UUID referencing the seed data, or rely on the `tests/` authentication fixtures.
